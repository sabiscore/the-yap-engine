# Contributing to The Yap Engine

> **Powered by SwarmXQ**

Thank you for your interest in contributing to The Yap Engine! Please ensure you adhere to the engineering contracts in `AGENTS.md` and follow the repository standards.

## Guidelines
1. Maintain zero-tolerance for `console.*` in src/services and src/routes.
2. Use `src/lib/env.ts` for all environment variable accesses.
3. Respect the SINGLE-7B LOCK for local LLM inference.
