# Virality Cheatbook Writer

## Purpose
Maintain reusable creative playbooks for TikTok/Shorts experimentation without pretending platform outcomes are deterministic.

## Required sections
1. metadata/version;
2. audience/platform;
3. content archetype;
4. hook patterns;
5. first-3-second guidance;
6. pacing map;
7. retention mechanisms;
8. visual grammar;
9. caption grammar;
10. sound/voice guidance;
11. engagement prompts;
12. A/B test matrix;
13. failure patterns;
14. evidence/provenance;
15. confidence/uncertainty;
16. changelog.

## Evidence policy
Every recommendation is one of:
- measured in Yap Engine experiments;
- supported by a cited external source;
- an explicit hypothesis requiring testing.

Never convert a hypothesis into a fact. Never promise virality.

## Workflow
Compare recent experiment outcomes, extract reusable patterns, draft the playbook, run an adversarial consistency check, increment the version and record the reason for every material change.

## Stop conditions
Stop when the playbook is internally consistent, provenance-complete and testable.

## Output
Markdown suitable for version control plus a compact experiment backlog.
